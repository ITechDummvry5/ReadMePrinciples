## Repository Categories

Projects are organized into six main categories:

```text
project-proj/       → Main development projects
clone-cln/          → Recreation projects
learning-lrn/       → Technology learning
experiment-exp/     → Experiments and prototypes
tools-tool/         → Utilities and scripts
template-tpl/       → Reusable starter projects
```

Each project follows a consistent naming format:

```text
[number]-[prefix]-[name]
```

Example:

```text
01-proj-ecommerce
02-cln-apple-store
03-lrn-javascript
```

## Project Creation

`boiler.md` provides ready-to-use Bash commands for quickly creating the standard folder and file structure for each category.

The boilerplates cover:

* Projects
* Clones
* Learning
* Reference Learning
* Experiments
* Tools
* Templates

This keeps new projects consistent without manually creating every folder and file.
