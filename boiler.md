# Project Boilerplate

Standard boilerplate commands for creating projects inside each repository category.

---

## Category Navigation

Use the appropriate command to enter the category folder before creating a project.

---

## Projects

```bash
# Enter the category folder
cd project-proj

# Create the project directory structure
mkdir -p 01-proj-name/{docs/screenshots,src/{assets/{images,icons,fonts,videos},css,js/modules}}

# Create project files
touch 01-proj-name/{README.md,LICENSE,.gitignore}

# Create documentation files
touch 01-proj-name/docs/{overview.md,setup.md,features.md}

# Create source files
touch 01-proj-name/src/index.html
touch 01-proj-name/src/css/{style.css,responsive.css}
touch 01-proj-name/src/js/script.js
```

## Learning

```bash
# Enter the category folder
cd learning-lrn

# Create the learning directory structure
mkdir -p 01-lrn-technology/{docs,src/{css,js}}

# Create project README
touch 01-lrn-technology/README.md

# Create learning documentation
touch 01-lrn-technology/docs/{01-technology-concept.md,02-technology-concept.md,03-technology-concept.md}

# Create shared source files
touch 01-lrn-technology/src/css/style.css
touch 01-lrn-technology/src/js/script.js

# Create practice folders
mkdir -p 01-lrn-technology/{01-technology-concept,02-technology-concept,03-technology-concept}
```
